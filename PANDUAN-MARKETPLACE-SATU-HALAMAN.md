# Baylos Marketplace Premium Satu Halaman

- Buka `index.html` untuk langsung melihat marketplace. Tidak ada tombol atau halaman portal.
- Masuk dan Daftar ada dalam dialog Akun; Pesanan Saya dan Admin melalui navigasi.
- Etalase tetap bergantung pada konfigurasi Supabase di `web/baylos-supabase-config.js`.
- Checkout, pembayaran, dan ongkir produksi belum siap dan tidak boleh digunakan untuk transaksi nyata.
- Unggah isi paket ke branch `supabase-integration`, bukan `main`. GitHub Pages harus diarahkan ke branch tersebut agar versi ini tampil publik.
- Uji pada Android dan cek tombol Masuk/Daftar, detail, keranjang, Pesanan Saya, dan pembatasan Admin.
