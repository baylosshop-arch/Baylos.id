# Tahap 11 — Uji manual galeri

| Uji | Cara | Hasil yang diharapkan |
|---|---|---|
| Produk dengan beberapa foto | Buka detail produk | Semua URL foto unik tampil |
| Buka zoom | Ketuk thumbnail | Dialog zoom terbuka pada foto yang dipilih |
| Navigasi sentuh | Geser kiri/kanan pada dialog | Foto berikut/sebelumnya tampil |
| Navigasi keyboard | Gunakan panah kiri/kanan | Foto berubah |
| Akses keyboard thumbnail | Fokus thumbnail, tekan Enter/Spasi | Dialog zoom terbuka |
| Foto kosong | Produk tanpa URL foto valid | Pesan foto belum tersedia tampil |
| Tutup dialog | Ketuk Tutup atau Escape | Dialog tertutup |
| Data produk | Refresh dan cari produk | Pencarian dan muat ulang tetap berfungsi |

Catat hasil aktual pada perangkat Android dan desktop. Pemeriksaan kode/sintaks saja tidak menggantikan uji browser.
